# Repository contract

Use the smallest complete change within the requested scope. Preserve unrelated
work. The Python package owns provider-independent contracts and bounded AXe
execution; provider modules own wire formats; planners do not inspect benchmark
oracle files. Grid planners receive screenshots and geometry, never accessibility
labels, selectors or control bounds. Benchmark evaluation occurs after the run.

Keep strict types, finite probabilities and validated answer IDs. Treat model
probabilities as uncalibrated beliefs. Do not turn a provider error, unsupported
capability or refused action into success. Keep files below 500 lines where
practical. Do not persist credentials, private goal strings or raw app content in
default telemetry. Saved benchmark evidence uses only the synthetic fixture.

Use uv for Python and rtk-prefixed shell commands in this workspace. Relevant
checks are strict typing, lint, unit tests, clean wheel installation and native
benchmark evidence. Do not commit, publish or change external accounts unless
the user requests it. Keep generated runtime artifacts under ignored paths.
